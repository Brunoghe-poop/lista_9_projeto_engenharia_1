## Sobre o Projeto
Este projeto demonstra a criação de um repositório C++ com rastreamento de código utilizando a metodologia Gitflow, Desenvolvimento Dirigido por Testes (TDD) e automação de compilação com Makefile.

## Estrutura
- `/src`: Código-fonte principal da aplicação
- `/include`: Ficheiros de cabeçalho (.hpp)
- `/test`: Ficheiros de teste de regressão
- `/bin`: Ficheiros binários gerados pela compilação

## Comandos
- Compilar aplicação: `make`
- Compilar testes: `make testes`
- Executar testes: `./bin/testeRegressivo.exe`
- Limpar binários: `make clean`
